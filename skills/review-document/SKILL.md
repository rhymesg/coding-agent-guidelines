# Review Document

Review documents and skills for concision, consistency, and readability while preserving meaning and accuracy.

## Modes

- Automatic final review after writing: apply corrections.
- User-requested review: report findings without editing. Wait for editing instructions unless already provided.

## Workflow

1. Read the document, [document-writing-guidelines](../document-writing-guidelines/SKILL.md), and other relevant project or format guidelines.
2. Review the document as a whole before checking individual passages, using those guidelines and the checks below.
3. Use [sync-docs](../sync-docs/SKILL.md) to identify stale related documents.
4. Apply corrections or report findings according to the mode.

## Concision

- Find repeated ideas across sections, unnecessary content, and sentences that can be combined more concisely without losing meaning.
- Identify information duplicated in other files that can be replaced with links to its source.
- Suggest moving specialized details into a linked file when they interrupt the main document.

## Consistency and Links

- Check consistency within the document and across related documents, including terminology, references, section numbers, examples, and claims.
- Validate file paths, anchors, and external links. Check that each target supports the referring text; report inaccessible targets as unverified.

## Purpose, Audience, and Readability

- Check that the document fits its purpose and audience.
- Check whether regrouping or reordering sections would make the document easier to follow.
- Read from the intended human reader's perspective; flag readability issues.

## Accuracy and Evidence

- Do not suggest clarifications for conditions a reasonable reader can infer from context.
- Verify factual statements against relevant source code, configuration, or authoritative sources.
- Match factual claims to evidence: state supported facts directly and qualify uncertain claims.
