# Writing a README

- Put every command in its own fenced `bash` block, ready to copy and paste.
- Explain each step in one short line.
- Link to the detailed document or source file instead of repeating its content.
- State what to do, not why. A README is an outline and a guide.
- Keep paragraphs to two sentences or fewer.
